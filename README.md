# Academic Pipeline

A visual workflow editor for processing structured text data with large language models.

**[Open the App](https://academic-pipeline-gui.onrender.com)** · **[Documentation](https://xingyuanzhao-project.github.io/academic-pipeline-public/)**

## What it does

Upload a CSV with text records, build a processing flow on a visual canvas, and run it against any OpenAI-compatible model. Summarise, classify, or extract structured labels from each row — with codebook-driven taxonomies and automatic checkpointing.

## Designed for

- **Political science** — coding legislative texts, media reports, human rights documentation.
- **Computational social science** — structured content analysis on large corpora.
- **Any domain** where tabular text data needs systematic LLM processing with reproducible codebooks.
